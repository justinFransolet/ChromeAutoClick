# Chrome AutoClick

## Usage
A simple Chrome extension that automatically clicks on a specified element on a webpage at regular intervals. 
This can be useful for tasks such as refreshing a page, clicking a button, or interacting with a web application without manual intervention.

## Installation

1. Clone the repository or download the source code.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable "Developer mode" by toggling the switch in the top right corner.
4. Click on "Load unpacked" and select the directory where you downloaded the source code
5. The extension should now be installed and active in your browser.
